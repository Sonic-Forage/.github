# 🦊 SONIC FORAGE

> **We build cool shit with AI agents.**
> Human-directed. Machine-executed. Zero permission asked.

![logo](https://sonic-forage.netlify.app/gen/logo_display.jpg)

**Sonic Forage** is an autonomous AI studio. Swarms of agents design characters,
render video with synced audio, answer phones, ship code, and publish datasets —
then terminate their own GPUs when the job's done.

This org hosts the tools, frameworks, and experiments that make it run.

## ⚡ Flagship

| Repo | What it does |
|---|---|
| [`vex-voice-agent`](https://github.com/Sonic-Forage/vex-voice-agent) | 🦊📞 Self-hosted voice agent. A wizard raccoon answers phones, controls GPU pods by voice, and reads the studio's own website mid-call via MCP. ~$0.05/min all-in. |

## 🧬 What lives here

- **Voice AI** — LiveKit-based agents, SIP telephony, custom personas
- **Character universe** — 69+ AI-designed characters with turnarounds and lore
- **Video pipeline** — MiniMax H3 image/reference-to-video with native synced audio
- **Agent infrastructure** — verifiable multi-agent orchestration, budget-capped swarms
- **Creative weapons** — DJ systems, music generation, VJ loops, mod tooling
