# Contributing to Sonic Forage

Welcome. Keep it creative, useful, and safe.

## Good first contributions

- Improve onboarding docs.
- Add example personas or payload templates.
- Add workflow cards that are dry-run/placeholder-safe.
- Improve verifier checks.
- Report confusing setup steps.

## Boundaries

Do not commit secrets, private endpoints, private media, model weights, or credentials. Do not add workflows that execute paid/GPU actions by default.
