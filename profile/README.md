# Sonic Forage

**Fork the signal. Build your own intergalactic DJ / creative-agent cockpit.**

Sonic Forage is a starter-kit ecosystem for people who want to create AI-powered performers, radio hosts, rave tools, launch cockpits, and timeline-safe music/show experiments.

## Start here

- **Starter kit:** https://github.com/Sonic-Forage/sonicforge-starter-kit
- **Community command center:** https://github.com/Sonic-Forage/sonicforge-swarm-command-center

## What you can build

- Your own AI DJ / MC / radio host persona.
- A local launch cockpit with safety gates.
- A show engine that mixes cached/generated tracks offline.
- ComfyUI / audio / visual workflow bindings without committing secrets.
- A forkable creative-agent payload pack.

## Hackathon lane

If you are here from a hackathon:

1. Open the starter kit.
2. Use **Use this template** or fork it.
3. Read `docs/start-here/CREATE_YOUR_OWN_SONICFORGE.md`.
4. Run `python3 scripts/verify_starter_kit.py`.
5. Introduce your idea in Discussions or Issues.

## Safety defaults

The starter kit is closed by default. It does not start GPUs, paid APIs, training, public posting, private uploads, or workflow prompts unless you intentionally configure and approve those gates locally.

Bring the weird. Keep the keys private. Share the build. 🛸
